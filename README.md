#  Webpage Design Practice — HTML & CSS

This repository showcases my hands-on practice in designing webpages using pure HTML and CSS.

## The project covers essential frontend concepts such as:

* Page layout structuring
* Styling with CSS (colors, spacing, fonts, shadows)
* Flexbox & Grid-based responsive design
* Header, footer, navigation bar, and form design
* Basic animations and hover effects

The aim is to improve HTML/CSS design skills by building neat, beginner-friendly webpage components and templates.
This repo acts as a personal practice playground while learning UI fundamentals.
